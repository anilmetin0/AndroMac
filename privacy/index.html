Privacy

Updated 26 November 2026

The short version

AndroMac has no account, no server and no analytics. Your phone and your Mac talk to each other directly on your own network, encrypted end to end. Nothing you sync passes through us or anyone else.

What the apps handle

Depending on what you turn on: notifications, the clipboard, SMS messages and contact names, call information, media playback, battery state, files you send, and the phone's screen when you mirror it. This data goes from one of your devices to the other and nowhere else.

The Mac keeps a clipboard history and a notification history on the Mac itself, and you can delete entries or clear them. The phone keeps its last 20 clipboard texts in memory only. Text messages are not stored on the Mac.

What goes to the internet

Only the update check. Once a day each app asks GitHub for the latest release and downloads it if you allow updates. GitHub sees that request like any web request; see the GitHub privacy statement. You can turn the check off in Settings → Updates.

This website

The site is hosted on GitHub Pages. It sets no cookies and uses no trackers. Your browser asks the GitHub API for the current version, star count and download count, and remembers your light or dark choice on your own device.

Permissions

Each permission is asked for when you turn on the feature that needs it. The list and what each one is for are on the main page. You can withdraw any of them in the system settings, or remove the apps entirely.

Contact

Questions or concerns: open an issue on GitHub. Security reports: see the security policy.
